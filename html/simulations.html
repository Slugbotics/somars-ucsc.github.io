About

The virtual world
before the real one.

We fly the drone in simulation before it leaves the ground. Bugs caught there are cheap to fix, so the team can test often without risking the aircraft.

Hardware-in-the-Loop (HIL)

Mission Gate

Scripted automated test flights. Every change must pass them before it flies.

Perception in the Loop

The aircraft's own YOLO11n detector runs in simulation, so detection gets tested too.
