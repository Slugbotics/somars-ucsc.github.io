# Reporting Security Vulnerabilities

If you believe you have found a security issue on this website, please report the following details to us in a private email directed to [slugbots@ucsc.edu](mailto:slugbots@ucsc.edu), and we will address it as soon as possible:

* Type of issue (e.g., buffer overflow, SQL injection, cross-site scripts)
* Full file path(s) to the source code affected by the issue
* The repository of the affected source code (git id, tags, branches, and or direct URLs)
* Any special system configuration required for us to reproduce the issue
* Step by step instructions on how the issue was produced
* Proof of concept or exploit code, if available
* Impact and severity of the issue, including how it might be exploited by an attacker

**Guidelines:**
* Please do not publicly disclose vulnerabilities until we have had time to push fixes.
* Please do not perform destructive testing or denial-of-service (DDoS) attacks against our infrastructure.

Any information provided is greatly appreciated and will help us run our operations more smoothly. Thank you!
